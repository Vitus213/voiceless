# CLI E2E CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `type4me-linux` verifiable as a command-line Linux voice input backend with unit, integration, and end-to-end tests, 90% coverage, pre-commit, and GitHub Actions CI.

**Architecture:** Keep production code small and dependency-free. Tests simulate external Linux tools with executable fixtures so CI can validate the real CLI orchestration without microphone, Wayland, GPU, or downloaded ASR models.

**Tech Stack:** Python 3.12, pytest, pytest-cov, ruff, pre-commit, Nix flake, GitHub Actions.
