# 控制台规格增量

## Purpose

让用户在浏览器和独立桌面窗口中完成 Voiceless 的首次设置、试说、日常听写与故障定位。界面按运行时能力提供操作，并给出清楚的结果和修复入口。

## ADDED Requirements

### Requirement: 首次试说验证实际链路

控制台 MUST 引导用户检查麦克风、选择识别路径、准备模型、验证快捷键并实际试说。现有可用配置 MUST 被识别并允许直接开始。试说默认进入可编辑练习框，真实上屏由用户另行触发。

#### Scenario: 从干净环境完成本地试说

- **WHEN** 新用户打开控制台并选择本地听写
- **THEN** 可查看麦克风电平、选择或安装兼容模型、通过界面或快捷键试说，并在练习框中看到可信的本地结果

#### Scenario: 设备、权限或下载失败后重试

- **WHEN** 首次试说因设备不可用、快捷键绑定未就绪或模型下载中断而停下
- **THEN** 页面指出失败步骤和修复入口，重试只需重新完成失败步骤，返回后继续现有进度

### Requirement: 统一的导航、状态与可访问操作

Web 和桌面界面 MUST 提供听写、输出、历史与文件、设置入口。诊断和实验功能可按能力进入。主要操作 MUST 有可见文字或可访问名称、键盘焦点和文字状态，且支持窄窗口、主题、简体中文、英文与减少动画。

#### Scenario: 从旧链接和窄窗口进入控制台

- **WHEN** 用户使用已有页面锚点，或在 390 CSS px 宽的窗口打开控制台
- **THEN** 可以抵达等价功能，主要内容无需横向滚动，导航入口可理解，焦点不被固定录音条遮挡

#### Scenario: 通过键盘试说和定位设置

- **WHEN** 用户关闭动画并使用键盘和读屏完成试说，再按名称找设备设置
- **THEN** 可定位、改动并保存设置，可听见会话阶段和结果，实时波形或局部文本不会持续打断读屏

### Requirement: 当前运行状态与诊断入口

控制台 MUST 展示实际识别行为、麦克风与快捷键就绪情况、最近一次交付以及可操作的失败原因。常驻录音条与详细诊断 MUST 来自同一运行状态，并明确区分配置选择、实际模型、实际设备和临时预览。

#### Scenario: 自动设备选择后查看实际结果

- **WHEN** `auto` 在当前主机上选择 Vulkan 或回退到 CPU，或最终识别与预览使用不同设备
- **THEN** 听写页和引擎页显示实际有效的设备和阶段，回退提示说明原因，诊断可导出脱敏信息

#### Scenario: 没有常驻服务时访问控制台

- **WHEN** 用户运行 `voiceless web`，目标地址未运行 Voiceless daemon
- **THEN** 可访问历史与配置操作，界面说明实时听写需要服务及其启动方式，并拒绝把占用端口的其他服务当成 Voiceless 打开

### Requirement: 回环控制台访问和离线运行

控制台 MUST 保持本机回环访问、会话凭据和同源写入校验。界面运行 MUST 无公网静态资源依赖。页面加载、查看历史、检查更新和导出诊断均不得将密钥、历史文字或录音发送到外部服务。

#### Scenario: 断网访问已安装的控制台

- **WHEN** 用户在无互联网的主机上启动控制台且本地模型已安装
- **THEN** 样式、脚本、诊断、历史与本地听写均能加载，界面指出只有显式选择的远程能力需要联网

#### Scenario: 非授权访问或写入

- **WHEN** 请求缺少本机访问凭据、来源不符或试图跨站发起写操作
- **THEN** 指定操作被拒绝，且响应不返回受保护的数据
