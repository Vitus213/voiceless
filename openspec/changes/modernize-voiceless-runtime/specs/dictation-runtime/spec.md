# 听写运行时规格增量

## Purpose

为快捷键、命令行、Web 控制台、桌面窗口和浮层提供一致的听写会话。用户可明确地录音、停止和取消，并在退出界面或连接恢复后继续了解会话及交付结果。

## ADDED Requirements

### Requirement: 多入口共享听写会话

同一用户和 Voiceless 数据目录 MUST 只有一个常驻运行时负责听写、热模型和系统快捷键。每次听写 MUST 有可跨客户端关联的身份，且任一时刻最多一个会话持有麦克风。关闭或重开界面 MUST 保留当前会话并允许快捷键继续工作。

#### Scenario: 多个入口同时开始

- **WHEN** 已打开 Web 和桌面窗口时，快捷键与 `voiceless ctl` 同时发送开始请求
- **THEN** 只有一个请求获得麦克风，其他请求看到已有会话或收到忙碌提示，所有界面展示同一个会话

#### Scenario: 关闭窗口时仍在听写

- **WHEN** 用户在录音中关闭 Web 和桌面窗口，然后用原快捷键停止
- **THEN** 当前会话完成识别和交付，重新打开界面后可查看其结果

### Requirement: 权威结果与取消

正常停止 MUST 按顺序提交采集尾帧，并生成至多一个权威最终结果。系统 MUST 区分临时文字、最终识别、文本处理和上屏结果。未进入交付的取消或失败 MUST 清理预编辑，且不得上屏或写成成功历史。

#### Scenario: 正常停止与重复请求

- **WHEN** 一个含语音的会话收到两次停止请求
- **THEN** 音频尾帧只提交一次，最终结果只生成一次，且最多进行一次可提交的上屏操作

#### Scenario: 用户取消或没有说话

- **WHEN** 用户在最终交付前取消，或在全静音录音后正常停止
- **THEN** 结果分别标记为取消或无语音，麦克风和预编辑得到释放，无上屏或成功历史

#### Scenario: 录音设备中途断开

- **WHEN** 麦克风在采集中断开且无法完整完成该会话
- **THEN** 系统报告录音中断，保留已获取的文字仅供显式恢复，且释放麦克风供下一次尝试

### Requirement: 客户端重连之后恢复状态

客户端 MUST 能区分连接中断与服务停止，并据当前运行实例和会话状态恢复展示。录音、识别、处理、交付、失败或取消 MUST 清晰可见，旧事件不得覆盖新会话或重复触发交付。

#### Scenario: 同一运行实例内重连

- **WHEN** 浏览器错过多个录音事件后在同一实例内重连
- **THEN** 页面恢复当前会话的阶段、已确认文字和可用操作，且只处理状态快照之后的有效更新

#### Scenario: 服务重启后恢复连接

- **WHEN** 运行时重启而页面仍保有旧会话与旧凭据
- **THEN** 页面能重新连接并显示新实例，旧会话不会被恢复为正在录音，旧操作也不会造成上屏

### Requirement: 听写延迟和质量可独立复核

维护者 MUST 能在目标环境按实际后端、设备和模式复核首个局部文本、松手到终稿和松手到实际交付。既有云端 `quick` 门禁和本地回放基线分别验收，报告 MUST 标出失败、回退和未验证的条件。

#### Scenario: 本地和云端分别实测

- **WHEN** 在版本化语料上回放本地 Vulkan、CPU 和显式云端识别，并在目标桌面验收上屏
- **THEN** 可按后端区分质量和各阶段时延，云端 `quick` 继续满足既有门禁，本地和远程润色结果分别报告

#### Scenario: 缺少实测环境

- **WHEN** CI 缺云端凭据、目标 GPU 或真实上屏窗口
- **THEN** 对应验收标为未验证，软件测试结果也不会被表述为实机通过
