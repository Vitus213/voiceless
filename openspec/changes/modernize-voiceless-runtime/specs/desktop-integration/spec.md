# 桌面集成规格增量

## Purpose

将语音输入带进用户当前使用的编辑器、终端和聊天窗口。桌面入口、麦克风、快捷键、浮层和上屏能力随操作系统及当前桌面会话正确工作，并给出可用的替代操作。

## ADDED Requirements

### Requirement: 独立窗口、托盘和服务生命周期

桌面启动入口 MUST 打开或聚焦一个 Voiceless 窗口，并使用现有运行时。支持托盘的桌面 MUST 提供打开窗口、暂停听写、重贴和退出等常用操作。用户可管理登录启动，关闭窗口不停止运行时，退出须明确处理活动任务。

#### Scenario: 从桌面启动器重复打开应用

- **WHEN** 用户已启动命令行 daemon，又连续两次打开桌面应用
- **THEN** 只显示一个设置窗口，复用已有的模型和快捷键，关闭窗口后托盘或启动器仍能再次打开它

#### Scenario: 无托盘或活动任务期间退出

- **WHEN** 桌面不提供托盘，或用户请求退出时仍有录音、转写或上屏
- **THEN** 启动器、窗口和 CLI 仍提供可用入口，退出前可选择等待或明确取消，登录启动设置不覆盖由系统管理的服务

### Requirement: 按平台能力提供麦克风和浮层

设置 MUST 展示识别到的麦克风、有效采集设备、权限状态和支持的浮层模式。当前麦克风失效时 MUST 显示可修复状态。浮层 MUST 只在启用后显示录音及识别状态，且不得夺取输入焦点。

#### Scenario: 切换或断开默认麦克风

- **WHEN** 用户切换系统默认设备或拔掉已经选定的麦克风
- **THEN** 设备列表和有效选择更新，下一次开始前可看到新设备或失效原因，独立选择的设备失效时可明确切回系统默认

#### Scenario: 合成器不支持浮层或系统功能

- **WHEN** 当前环境缺少所需的桌面协议、系统权限或前台窗口信息
- **THEN** 对应能力展示原因和可用替代路径，支持浮层时其反馈与实际会话一致且输入焦点保持原位

### Requirement: 全局听写快捷键与冲突报告

用户 MUST 能设置按住说话、点按开始与停止、取消、原文直出和重贴的可用快捷键。系统 MUST 标明实际绑定、冲突与权限，并保留用户已配置的合成器或 CLI 入口。

#### Scenario: 录制并试用支持的手势

- **WHEN** 用户分别用已绑定的按住、点按和取消手势操作
- **THEN** 可预测地开始、停止或取消同一会话，键盘重复与冲突不会造成多次开始或提交

#### Scenario: 快捷键被占用或未授权

- **WHEN** 新组合键被占用，或用户拒绝系统的全局快捷键权限
- **THEN** 已生效的绑定保持可用，界面提供重新录制或配置系统快捷键的途径

### Requirement: 在正确的目标交付结果

自动上屏 MUST 使用平台支持的方法，并检查录音时的目标是否仍可安全写入。可用时保留 Fcitx5 预编辑、直接提交和剪贴板等已明确选择的方式。交付状态 MUST 区分已提交、已复制、未提交与结果无法确认。

#### Scenario: 在编辑器和终端交付

- **WHEN** 用户分别在受支持的编辑器、输入法和终端完成听写
- **THEN** 文本通过当前目标适用的方式进入该目标，终端输入不会自动发送执行键，预编辑在结束时清理

#### Scenario: 焦点改变或交付结果无法确认

- **WHEN** 识别期间焦点移到另一应用、系统不提供可靠目标，或一次上屏返回不确定状态
- **THEN** 文本可供用户复制或显式重贴，运行时不对另一个窗口盲目提交也不自动重复上屏
