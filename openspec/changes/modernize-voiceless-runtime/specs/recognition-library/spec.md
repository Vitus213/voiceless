# 识别历史规格增量

## Purpose

让用户查找、修订和带走自己的听写结果。已保存的旧文本和录音可继续访问，新结果可追踪来源、纠错版本及存储期限，并能按需要删除或导出。

## ADDED Requirements

### Requirement: 全量历史搜索与兼容读取

历史 MUST 支持跨页搜索中英文原文和最终文本，按日期、模式、应用、模型及是否有录音筛选。升级 MUST 保留已有记录和可播录音。原有记录缺少新增字段时，页面显示未记录状态。

#### Scenario: 搜索旧记录和跨年记录

- **WHEN** 用户升级含早期记录的安装并搜索中文词、英文 API 名或上一年的结果
- **THEN** 能查到当前页之外的匹配项，同年月日但不同年份的记录可区分，缺少新增属性的记录仍可打开或导出

#### Scenario: 分页期间有新录音完成

- **WHEN** 用户读取下一页时后台完成一条新听写
- **THEN** 继续浏览不会漏掉原查询中的结果或重复显示，同一筛选条件可用于导出

### Requirement: 回放、重转写与版本恢复

有录音的条目 MUST 可回放并重新识别。纠错或重新识别生成可比较版本，用户确认后才替换当前版本，且仍可恢复原文和已保留版本。无音频条目继续支持文本处理。

#### Scenario: 用另一模型重转写并恢复

- **WHEN** 用户回放录音，用所选模型或语言再次识别，预览并采用新文本后恢复旧版
- **THEN** 两次文本及其来源可对照，恢复不删除历史版本，也不会向前台窗口自动上屏

#### Scenario: 录音缺失或重转写失败

- **WHEN** 录音已删除、被清理或重转写失败
- **THEN** 条目仍可复制、纠错、搜索和导出，界面显示失败原因且当前文本保持可用

### Requirement: 文本、录音和失败恢复的保留策略

用户 MUST 能独立设置文本与音频的保存期限或关闭保存，并预览删除影响。所选记录支持导出为文本、Markdown、CSV 或 JSON，音频只有显式选择才导出。失败恢复材料为独立的可选保留项。

#### Scenario: 先清理录音再清理文本

- **WHEN** 音频到期而文本仍在保留期，之后用户删除该批文本
- **THEN** 录音先失去播放入口而文本继续可查，删除文本后搜索和导出也不再包含它

#### Scenario: 导出选择和恢复失败会话

- **WHEN** 用户导出筛选后的文本并从启用的恢复区重开一段失败录音
- **THEN** 导出匹配选择且默认无音频，恢复录音可显式转写但不会充当已成功的听写
