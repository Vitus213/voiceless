# 文件转写规格增量

## Purpose

支持在保留日常低延迟听写的同时处理长录音和视频。用户能批量导入文件、选择识别方式、观察进度并恢复任务，将带时间信息的结果保存成可使用的文本或字幕。

## ADDED Requirements

### Requirement: 批量导入与可验证的转写结果

界面 MUST 支持选择或拖入多个媒体文件，提供常用音视频格式的能力说明。任务 MUST 显示输入、模型、语言、传输方式及错误状态。输出 MUST 可导出为纯文本和分段 JSON，具备段落时间戳时可导出 SRT/VTT。

#### Scenario: 导入音视频和导出字幕

- **WHEN** 用户导入 WAV、FLAC、MP3、M4A、Ogg 或 MP4 中当前支持的文件，并选择可产生时间戳的模型
- **THEN** 可逐条查看转写结果和来源，导出的 SRT/VTT 时间线来自媒体解码和识别分段，结果不会上屏

#### Scenario: 文件、编解码器或云端传输不可用

- **WHEN** 用户选了不支持、损坏、无法读取的文件，或云端转写尚未获得用户授权
- **THEN** 相应条目指出具体原因和处理办法，其他文件仍可继续，本地处理不会上传媒体

### Requirement: 作业可暂停、取消和恢复

转写队列 MUST 由常驻运行时处理，显示排队、运行、暂停、取消、完成和失败状态。关闭界面不影响进度，进程重启后 MUST 能恢复已完成段落与任务意图，取消或重试不得重复产生结果。

#### Scenario: 退出界面或重启后恢复长任务

- **WHEN** 用户关闭窗口，并在长文件转写中重启运行时
- **THEN** 队列和已完成段落仍可查看，任务可从安全边界恢复，源文件失效时提示重新选择

#### Scenario: 暂停、重试或取消转写

- **WHEN** 用户暂停再恢复一项任务，或在某一段失败后重试，或显式取消
- **THEN** 当前行为与任务状态一致，已完成段不会重复，取消后不会继续识别或发布完成结果

### Requirement: 后台任务让出实时听写资源

文件转写、历史重转写、基准和会议后的识别 MUST 遵守后台任务资源限制。实时听写需要同一解码资源时 MUST 有优先权，界面能说明后台任务何时等待、何时恢复。

#### Scenario: 长文件处理期间开始听写

- **WHEN** 长媒体正在使用同一设备，而用户用快捷键开始听写
- **THEN** 后台工作在有界时间内让出资源，听写按该后端的延迟门禁运行，后台任务随后恢复且保持已完成进度
