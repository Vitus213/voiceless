# 会议与标注规格增量

## Purpose

提供长会话记录与带语音的屏幕反馈。用户明确选择采集范围，实时看到采集状态，能在录制中断后取回已保存内容，并决定哪些内容留在本地或发送给其他工具。

## ADDED Requirements

### Requirement: 独立的会议采集和恢复

会议 MUST 是独立的可选工作流。用户明确选择麦克风和受支持的系统音频来源并启动录制。界面 MUST 显示采集范围、录制状态和数据位置，停止后可继续转写，异常中断可恢复已保存片段。

#### Scenario: 选择会议输入并完成录制

- **WHEN** 用户授权并开始采集麦克风及平台支持的系统音频
- **THEN** 录制状态和来源持续可见，停止后生成可独立处理的会议记录，不触发日常听写上屏

#### Scenario: 授权拒绝、来源失效或进程中断

- **WHEN** 系统拒绝一个来源、输入设备失效或进程中断
- **THEN** 告知用户缺失来源与可选操作，保留已安全写入的片段，并在下次启动时提供恢复或丢弃选择

### Requirement: 可校对的会议整理

会议结果 MUST 支持按时间跳转、说话人编辑、段落校对、标题、要点和导出。自动分离、总结和外部提供方须明确选择，未确认的说话人应保留不确定状态。

#### Scenario: 校对会议并选择整理方式

- **WHEN** 用户查看会议转写，修改说话人并选择本地或远程整理
- **THEN** 时间戳与可播放片段对应，自动标注可校正，输入范围与实际处理方式可见，只有授权给远程的内容会发送

### Requirement: 带语音的屏幕标注

受支持平台 MUST 允许选择屏幕区域或窗口、绘制标注并附加语音转写。用户可预览、保存、复制或明确发送选中的内容，采集过程始终可见，取消后不得外发。

#### Scenario: 录制并复核带语音的屏幕反馈

- **WHEN** 用户选择目标区域并录制一段带标注的说明
- **THEN** 可预览屏幕范围、标注与转写，只有用户选择的结果被保存、复制或发送到所选目标

#### Scenario: 平台不支持屏幕采集或用户取消

- **WHEN** 平台没有对应能力、用户拒绝授权或在预览确认前取消
- **THEN** 给出未完成原因和可用替代路径，临时片段得到清理，目标工具不会收到内容
